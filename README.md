# 🎶 Vocaloid Cafe Website

A responsive **Vocaloid-themed cafe website** built with **React + Vite + TypeScript + TailwindCSS**.  
This project is a practice/demo site that introduces a fictional cafe with sections for **About, Menu, Events, and Contact**.

---

## ✨ Features
- ⚡ **Vite + React (TypeScript)** for fast development
- 🎨 **TailwindCSS** for styling (utility-first, fully responsive)
- 📱 **Responsive design** (mobile, tablet, PC)
- 🗺️ **Google Maps embed** for location
- 📬 Simple **contact form** with validation
